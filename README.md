# miniflux-theme

Theme and custom UI tweaks for Miniflux Web.

## Files

- `forest.css`: custom theme stylesheet
- `dark.css`: dark theme overrides
- `mark-page-read-scroll-top.js`: custom JavaScript that scrolls the feed back to the top after confirming `Mark this page as read`

## Usage

Paste the contents of `mark-page-read-scroll-top.js` into Miniflux `Settings -> Display -> Custom JavaScript`.
